Step 1

AST Ingestion

Uses ts-morph to parse TypeScript abstract syntax trees, resolving @/* aliases and barrel re-exports into static import graphs.

Step 2

FalkorDB Engine

Stores files as nodes and imports as edges. Executes sparse-matrix traversals in 3–5ms to identify multi-hop blast radiuses.

Step 3

Sarvam AI Planner

Sarvam-105B analyzes the affected nodes, explains what functions break, and generates a step-by-step safe refactoring sequence.

Step 4

MCP Execution

Exposes tools to Cursor, Claude, and Antigravity over the Model Context Protocol, executing safe multi-file edits automatically.
