⚡ ZERO MANUAL SETUP

1-Click Agent Setup Prompt

Paste this prompt directly into your AI coding assistant (Cursor, Claude Desktop, or Antigravity). The agent will autonomously spin up FalkorDB, install Sarvam-Ripple, index your project, and enforce graph-safety automatically: 

Please install and set up Sarvam-Ripple for this workspace by performing the following steps:

1. Check FalkorDB availability:
   - Check if FalkorDB is reachable on localhost:6379.
   - If not reachable, check if Docker is installed and running (`docker ps`).
   - If Docker is running, start FalkorDB:
     docker run -d --name falkordb --restart unless-stopped -p 6379:6379 -p 3000:3000 falkordb/falkordb:latest
   - If Docker or FalkorDB is NOT installed on this machine, inform the user:
     "Neither Docker nor FalkorDB was detected locally. You have two instant options:
      Option A (Zero-install Cloud - Recommended): Create a free database in 30 seconds at https://app.falkordb.cloud (no Docker required). Share your Host, Port, and Password, and I will configure .env automatically!
      Option B (Local): Install Docker Desktop (https://www.docker.com) or install FalkorDB natively (`brew install falkordb/tap/falkordb` or `curl -fsSL https://www.falkordb.com/install.sh | bash`)."

2. Clone and build Sarvam-Ripple into a local helper folder:
   git clone https://github.com/shriharidesai209-commits/Sarvam-Ripple.git .sarvam-ripple
   cd .sarvam-ripple && npm install && npm run build && cd ..

3. Configure environment:
   In `.sarvam-ripple/.env`, set:
   SARVAM_API_KEY=<your_sarvam_api_key>
   FALKOR_HOST=localhost (or your FalkorDB Cloud host)
   FALKOR_PORT=6379 (or your FalkorDB Cloud port)

4. Index this repository into FalkorDB:
   node .sarvam-ripple/dist/cli.js index .

5. Add the following rule to your instructions:
   "Before modifying, renaming, or refactoring any exported function, type, or component, you MUST consult Sarvam-Ripple's generate_safe_plan tool (or run `node .sarvam-ripple/dist/cli.js plan <file> -c '<change>'`) to inspect the multi-hop blast radius and apply all edits in topological safe order so nothing breaks."

Confirm when setup and indexing are complete!

Why Flat Text Search and Linters Fail

Traditional Grep & Vector RAG

Standard search is syntactically blind to barrel files (export * from './...') and tsconfig path aliases. A generic identifier like id generates thousands of false positives, while indirect dependencies 2 to 4 hops away are completely missed.

Sarvam-Ripple Deterministic Graph

FalkorDB stores the true, resolved property graph. Paths are traversed using matrix multiplications, discovering transitive dependencies with mathematical certainty and sorting them into a clean topological execution order.

01 / FLAGSHIP REFACTORING

generate_safe_plan

Combines FalkorDB graph traversal with Sarvam AI reasoning to generate a complete visual blast radius diagram and an exact step-by-step code modification plan in safe topological order.

Inputs: path: string, proposedChange: string

02 / AUDITING

blast_radius

Calculates all files that transitively import the target file up to N hops away. Returns structured dependency counts and an in-chat visual Mermaid diagram.

Inputs: path: string, maxHops?: number (default 4)
// blast_radius response snippet 
{
  "target": "src/types/api.ts",
  "totalDependents": 4,
  "byDistance": {
    "1": ["src/services/auth.ts"],
    "2": ["src/components/UserProfileCard.tsx"],
    "3": ["src/pages/Dashboard.tsx"],
    "4": ["src/App.tsx"]
  }
}
03 / PROVENANCE

why_affected

Finds the shortest import chain between two distant files, explaining why modifying file "to" will break file "from".

Inputs: from: string, to: string
// why_affected response snippet 
{
  "from": "src/App.tsx",
  "to": "src/types/api.ts",
  "affected": true,
  "hops": 4,
  "chain": ["src/App.tsx", "src/pages/Dashboard.tsx", "src/components/UserProfileCard.tsx", "src/services/auth.ts", "src/types/api.ts"]
}

GET STARTED IN 3 MINUTES SETUP GUIDE

Install and run Sarvam-Ripple.

Follow these simple steps to set up FalkorDB, build Sarvam-Ripple, and connect it to your AI coding agent.

1

Start FalkorDB

Run FalkorDB locally in Docker with the interactive visual studio enabled:

docker run -d --name falkordb -p 6379:6379 -p 3000:3000 falkordb/falkordb:latest
2

Clone & Build Sarvam-Ripple

Clone the repository and compile the TypeScript project:

git clone https://github.com/shriharidesai209-commits/Sarvam-Ripple.git
cd Sarvam-Ripple && npm install && npm run build
3

Index Your Project

Point the indexer to your TypeScript/JavaScript codebase:

node dist/cli.js index /path/to/your/project
4

Connect to Cursor / Claude Desktop

Add Sarvam-Ripple to your MCP configuration (claude_desktop_config.json or Cursor MCP settings):

{
  "mcpServers": {
    "sarvam-ripple": {
      "command": "node",
      "args": ["/absolute/path/to/Sarvam-Ripple/dist/server.js"],
      "env": {
        "SARVAM_API_KEY": "your_sarvam_api_key",
        "SARVAM_MOCK": "false"
      }
    }
  }
}
